# Archimedes

Archimedes is an AI architecture workbench for evidence-backed architecture design.

## Repository Layout

- `docs/` design and planning documents
- `src/` application source code
- `tests/` automated tests
- `prompts/` agent and routine prompts
- `kb_sources/` curated knowledge base source docs
- `tools/` deterministic tool modules
- `frontend/` Streamlit UI
- `scripts/` utility and provisioning scripts

## Quick Start

1. Create a virtual environment.
2. Install dependencies from `requirements.txt`.
3. Copy `.env.example` to `.env` and set values.
